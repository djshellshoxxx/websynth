# Terrain Loom (WebSynth) Wiki

Terrain Loom is an experimental browser synthesiser from Circuit Drift Labs. Each voice scans a two-dimensional
mathematical terrain, and the player reshapes the terrain. The repository is named `websynth`; the product is Terrain Loom.
